# morinodrive

石川県金沢市のもりの里を中心に、田上・若松・金沢大学の前までを車で自由に走るブラウザゲームです。
地元の人や学生が遊ぶための、目的のない散策ドライブを目指しています。

いまは **走行試作 第7版** です。地形・建物・道路を公開の地図データから作った、もりの里・若松・田上・角間(金沢大学の前まで)を走れます。建物の色や屋根の形はまだ推定です。

## 遊び方(手元で動かす)

ES モジュールを使うので、`index.html` を直接開くのではなく、ローカルのサーバー経由で開きます。

```sh
npm run serve        # python3 -m http.server 8000
# → http://localhost:8000/
```

車のデータ(`assets/car.glb`)は入っていないので、先に下の「車のデータを用意する」を済ませてください。

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| アクセル | W / ↑ | RT |
| ブレーキ(止まって長押しで後退) | S / ↓ | LT |
| ハンドル | A D / ← → | 左スティック |
| サイドブレーキ | Space | A / B |
| 視点(後ろ・運転席) | C | Y |
| 見回す | マウスでドラッグ | 右スティック |
| 道路に戻る | R | Back |
| 操作の案内 | H | X |
| 地図を出す・しまう | M | 十字キー上 |
| 一時停止 | Esc | Start |

## 車のデータを用意する

元の車のモデルは権利の確認が済むまで公開リポジトリに入れません(`.gitignore` で除外)。
手元に元データ(GLB)がある場合は、次の手順で加工済みの `assets/car.glb` を作ります。

```sh
npm install
cp 元データ.glb tools/car/input/car.glb
npm run car:plate    # 架空の「金沢」ナンバーの画像を作る
npm run car:build    # 加工して assets/car.glb に書き出す
```

`tools/car/build-car.mjs` がしていること:

- 部品ごとの座標をまとめて焼き込み、左右反転した部品の面の向きを直す(元データでは右前ドアの外板が裏返っていた)
- タイヤ4本を「転舵する軸」と「回転する部分」に分け、ブレーキキャリパーは回転させない
- 内装と一体だったハンドルを、軸のまわりの範囲で切り出して別の部品にする
- ナンバープレートの画像を差し替える
- ポリゴンを減らし(約34.5万 → 約18万)、テクスチャを WebP にし、meshopt で圧縮する(19MB → 3.3MB)

ハンドルの中心と軸の向き、メーター・ナビ画面の位置は、元データを運転席の視点から raycast して測った値です。
別の車に替えるときは、これらの値(`build-car.mjs` の `SW`、`js/instruments.js` の配置、`js/main.js` の `EYE`)を測り直します。

## 地図データ

範囲は北緯 36.535〜36.566°、東経 136.677〜136.714°(約 3.3km × 3.4km)。遠景用に周りの約 20km 四方の地形も入れています。

| 使ったデータ | ゲームでの使い道 |
|---|---|
| 国土地理院 標高タイル(DEM5A / DEM5B / DEM10B) | 地形(8m 間隔)・遠景の山(60m 間隔) |
| 国土地理院 最適化ベクトルタイル | 道路中心線(種別・幅員区分)、川・水面、町名(住居表示板) |
| PLATEAU 金沢市 2024 建築物 LOD1 | 建物 15,349 棟(形・高さ・用途・階数) |
| PLATEAU 金沢市 2024 道路 LOD1 | 道路の範囲(車道+歩道)、橋 43 か所 |
| 国土地理院 シームレス空中写真 z18(約 0.4m/画素、992 枚) | 建物ごとの屋根の色、植物が写る所への庭木・低木・生垣、店の前の舗装(駐車場) |
| 国土地理院 シームレス空中写真 | 林・畑・田・草地・遠景の山の地面の下地(z16 約 1.9m/画素、遠景は z13) |
| PLATEAU 金沢市 2024 土地利用(MVT) | 地面の塗り分け(田・畑・山林・公園・住宅地など)と木・庭木の配置 |
| Mapillary(路上の写真、CC BY-SA 4.0) | 道路から見える建物の壁の色(360°写真)、写真から検出された電柱・街灯・標識・マンホールの位置 |
| OpenStreetMap(Overpass API) | 車道の幅(車線数・道路の種類)、一方通行、区画線、横断歩道 149、信号機 49 交差点、路線名・制限速度 |

出典:国土地理院(地理院タイル)、国土交通省 PLATEAU 金沢市 2024、© OpenStreetMap contributors を加工して作成

`assets/map/` のうち Mapillary から作った部分(壁の色 `wc`、電柱・街灯・標識・マンホールの位置)は [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) に従います(© Mapillary contributors)。

`assets/map/` のうち OpenStreetMap から作った部分(車道の範囲・区画線・横断歩道・停止線・信号機・道路の中心線)は [ODbL](https://opendatacommons.org/licenses/odbl/) に従います。

### 作り直し方

```sh
npm install
export NODE_USE_ENV_PROXY=1             # プロキシ経由のときだけ
node tools/map/fetch-plateau.mjs bldg,tran   # PLATEAU の zip から範囲の 3次メッシュ分だけ取り出す(約 170MB)
node tools/map/fetch-gsi.mjs                 # 標高とベクトルタイル
# OpenStreetMap:tools/map/raw/osm.json に Overpass API の結果を置く(取得の式は下)
node tools/map/fetch-luse.mjs                # PLATEAU の土地利用(MVT)
node tools/map/fetch-photo.mjs               # 国土地理院の空中写真(地面の下地)
node tools/map/photo18.mjs                   # 空中写真 z18(屋根の色・植物・駐車場の判定用)
# Mapillary(アクセストークンが必要。プロキシが Authorization ヘッダーに入れる設定)
node tools/map/mly-survey.mjs                # 範囲の写真の一覧
node tools/map/mly-features.mjs              # 写真から検出された物の位置
node tools/map/build-map.mjs                 # いったん作る(道路の中心線が次で要る)
node tools/map/mly-align.mjs                 # 撮影の連続ごとに道路へ位置合わせ
node tools/map/mly-panos.mjs                 # 360°写真を 12m おきに取得
node tools/map/mly-colors.mjs                # 壁の色を読む
node tools/map/build-map.mjs                 # 壁の色と検出物を入れて作り直す
node tools/map/parse-plateau.mjs             # CityGML → JSON
node tools/map/build-map.mjs                 # assets/map/ を作る
node tools/map/preview.mjs                   # 確認用の上から見た図(raw/preview.png)
```

- 取り込んだ元データは `tools/map/raw/` に置かれ、リポジトリには入れません(`.gitignore`)。
- 道路は 1m 間隔の「土地の区分」画像(`assets/map/land.png`:R 道路・G 水面・B 建物と敷地)として地形の表面に描きます。路面と地形が必ず一致し、物理の路面判定と建物の当たり判定もこの画像を使います。
- PLATEAU の道路の範囲には歩道も含まれるので、車道は OpenStreetMap の中心線を車道の幅(車線数 × 3.0〜3.25m + 路肩、車線数がなければ道路の種類から)で太らせた形とし、残りを歩道として塗り分けます。OSM に無い細い道は国土地理院の中心線から幅 4.5m で補います。
- 路面のガタつきを抑えるため、道路の中心線に沿って標高をなめらかにし(約 12m の幅で平均)、道路の横方向は平らにしています。2m おきの勾配の変化が 5cm を超える箇所は 13.3% → 4.3%、道路の横の傾きは平均 5.8% → 0.8%。
- 区画線は OSM の車線数・一方通行・道路の種類から。対面通行の幹線道路と 4 車線以上は黄色の中央線、それ以外の 2 車線は白の破線、多車線は車線境界線(白の破線)、主な道路には外側線。交差点の手前で切ります。
- 信号機は OSM の信号のノードに、入ってくる方向ごとに 1 基(交差点の向こう側、左の路肩から腕を出す形)。2 方向を交互に、青 26 秒・黄 3 秒・全赤 2 秒で切り替えます。停止線は信号の手前の左側の車線に。

Overpass API の取得の式(overpass-api.de につながらないときは overpass.kumi.systems):

```
[out:json][timeout:120];
(way["highway"](36.530,136.670,36.571,136.721);
 node["highway"~"traffic_signals|crossing|stop"](36.530,136.670,36.571,136.721);
 nwr["amenity"](36.530,136.670,36.571,136.721);
 nwr["shop"](36.530,136.670,36.571,136.721););
out body;>;out skel qt;
```
- 電柱は中心線に沿って約 35m おきに道路の外側へ置いた推定です。木は建物や道路から離れた斜面・山に置いています。
- 切妻屋根は、住宅のうち形がほぼ長方形のもの(約 7,300 棟)に、長い辺の向きで載せています。倉庫・体育館・寺社・町家風の家にも、種類に合った勾配で載せます。
- 建物の床は敷地のいちばん高い地面に合わせ、低い側は窓のない基礎の壁で地面まで下ろします(斜面で埋まらないように)。
- 建物の種類は PLATEAU の用途と OSM の店・施設(196 件、うち 99 件を建物に割り当て)から決め、住宅・町家風・集合住宅・事務所・学校・体育館・店・コンビニ・大型店・医院・公共施設・倉庫・寺社などで外壁の模様(`facadeAtlas`)と屋根を作り分けます。店名の看板(51 件)は道路に面した壁に付けます。
- 縁石は車道の縁のうち歩道・分離帯に接する所(約 164km)、中央分離帯は向きが逆の一方通行が平行に並ぶ所から作り、植え込みと木を置きます。主な道路で歩道が 2.5m 以上ある所には街路樹を 12m おきに。電柱・信号の柱・街路樹・植え込みには当たり判定があります。
- 屋根の色は空中写真で建物の内側を 0.8m おきに読んだ中央値(写真の霞を差し引いて補正)。
- 住宅地・公園などで空中写真に緑が写る所に庭木と低木(約 4 万)。
- 駐車場:OSM の駐車場 41 か所と、店の前で空中写真に灰色の舗装が写る所に、2.5m × 5m の区画の白線(約 1.4 万区画)。
- 敷地の境:住宅地で道路に面した所に、ブロック塀・生垣(空中写真に緑が写る所)・フェンスを、7〜13m の区画ごとに門や駐車スペースの切れ目つきで(約 64km)。当たり判定あり。
- Mapillary の 360°写真(338 枚を使用)に建物の壁を投影し、道路から見える 222 棟の壁の色を写真から取る。写真の位置は GPS の誤差が最大 20m ほどあるので、撮影の連続ごとに道路の中心線へ合わせ(ICP)、道路から 4m 以内に収まり、橋・高架の上でない写真だけ使う。色は前方のアスファルトを灰色とみなして白とび・青かぶりを補正し、窓や影より明るい側を壁の色とする。
- 写真がある道では、推定の電柱を Mapillary が検出した電柱(1,028 本)に置き換え、街灯 736 本、種類が分かった標識 164 枚(駐車禁止・制限速度・直進・止まれなど)、マンホール・雨水ます 508 か所を置く。
- 電線(電柱どうしを 3 本、近くの分だけ描く)、道路の脇が落ち込んでいる所のガードレール(約 5.7km)、OSM の制限速度からの速度標識(55 か所)。
- 建物の足元の地面と壁の下側を暗くして、地面に据わって見えるように。
- 木と庭木は土地利用から:山林は密に杉と広葉樹、公園・自然地はまばらに、住宅地は建物まわりの敷地に庭木と低木。512m の塊ごとに分け、1.1km より遠い塊は描きません。

## 軽くするための工夫

- 地形は 256m の塊ごとに、450m より遠い塊は 2 マスおきの粗い形に切り替え(継ぎ目は縁から垂らした面で隠す)
- 木は 256m の塊ごとに近い形・遠い形・描かないを切り替え、林の木は影を落とさない
- カーナビ・ミニマップの地図は 1 フレームに 1 枚ずつ作る(まとめて作ると一瞬止まるため)
- 描画の速さを見て画素の細かさを 0.8〜1.5 倍で自動調整。一時停止の画面で「画質:標準/軽量」を切り替えられます
- 運転席から見ていないときはメーターとナビ画面の書き換えを減らす

## 音

音のファイルは使わず、Web Audio でその場で作っています。e:HEV らしく、ふだんはモーターのうなり、強く加速したときや 75km/h 以上ではエンジンが回ります。ロードノイズ(砂利・草の上ではざらつき)、風切り音、タイヤのきしみ、ぶつかった音、後退のブザー。運転席の視点では車内のこもった音になります。一時停止の画面で音を切れます。

## 運転の手助け

実車のフリードにある横すべり防止(VSA)に当たるものを入れています。車の向きの変わる速さが、ハンドルとタイヤの限界から見込める値を超えると、向きを戻す力をかけて駆動を絞ります(メーターに黄色の表示)。キーボードでハンドルを離しているときは、すべった向きへ前輪を向けて立て直しを手伝います。90km/h でサイドブレーキを引いて急ハンドルを切っても、手を離せば約 0.6 秒で戻ります(`node tools/test/slide-test.mjs`)。

## 画面のつくり

AI が作った画面に見えないよう、街の中にある表示物の言葉づかいに寄せています。

- 現在地は青い住居表示板(白い縁取り)
- 操作の案内は案内標識の体裁
- 地図と読み込み画面は地形図の地色と等高線
- 走行中の画面にはほとんど何も出さない(後ろからの視点のときだけ右下に速度、左下に地形図の体裁のミニマップと町名・路線名)
